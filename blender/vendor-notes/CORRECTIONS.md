# 자동 보정 코드 인수인계 (contact-v2)

## 실행과 결과

`run_all.ps1`은 원본 input/*.glb에서 기준점을 자동 추정하고 output_corrected/<모델>/에 결과를 만든다. 기존 output/은 비교용으로 보존된다. `-UseLandmarks`는 기존 output/의 기준점을 사용한다. `-OutputRoot output_repeat`로 별도 반복 재생성을 할 수 있다. `-LandmarksRoot`로 기준점 폴더도 지정할 수 있다.

Blender에 현재 열린 이전 씬을 저장해서 수정 결과를 덮어쓰지 말 것. 최신 검토 대상은 output_corrected의 .blend다.

## 구현

- poses.py: 앉기 높이 계산에 접힌 뒷다리를 포함한다. 꼬리는 골반 높이와 분리해 유한 개 후보에서 접지·늘어남을 함께 평가한다. 유지 자세의 호흡 시작 위상을 맞춰 전환 끝점 차이를 줄였다.
- contact.py: 엎드리기/일어나기의 발목 목표 경로를 끝점 사이에서 보간하고 임시 IK로 푼다. 발의 월드 방향도 유지한다. 실제 변형 메시의 다리별 최저점으로 최대 8회 보정한다. 골반 상승 보정 한도는 정규화 높이의 0.12다. 실패는 검사에서 드러나며, 무한 반복하지 않는다. 앉기는 기존 수직 앞다리 전용 해법을 사용해 이중 IK의 뒤집힘을 피한다.
- 손으로 잡은 lie.json은 수정하지 않았다. 다른 체형은 손 포즈의 몸통을 기준으로 견갑골·앞다리 방향을 맞춘다. 모델 이름은 손 포즈의 source_model과 비교하며, 낯선 모델은 체형 보정을 적용한다. 새로운 체형에서 항상 자연스럽다는 보장은 없다.
- weights.py: UV 경계의 같은 위치를 묶어 가중치를 평균화하고 실제 메시 연결선을 따라 4회 완화한다. 메시·UV 자체는 그대로다. 목과 귀처럼 단지 공간적으로 가까운 부분끼리는 연결하지 않는다. 반대쪽 다리로 새는 영향은 부드럽게 제한하고 최종 최대 4개 가중치를 정규화한다. 꼬리/허벅지 가중치를 강제로 분리하는 시도는 일부 모델을 악화시켜 채택하지 않았다.
- validate.py: 모든 정수 프레임, 바인드 기준 늘어남, 발별 최저점 범위, 반복 끝점 차이, 프레임 간 최대 정점 이동을 기록한다. 기존 12프레임·클립 첫 자세 기준 검사의 사각지대를 줄였다.
- rig.py: clip issues가 있으면 status=needs_review, quality.accepted=false, 종료 코드 2다. 실패는 failed/1. 기존 warning을 처리하던 호출자는 needs_review도 처리해야 한다. 결과가 생성됐다는 사실은 품질 승인과 다르다.

## 17개 클립과 연결

기존 15개에 FallAsleep, WakeUp을 추가했다. 두 클립은 각각 24프레임 길이(끝점 포함 키 25개)다.

`LieIdle → FallAsleep → Sleep → WakeUp → LieIdle → GetUp → Idle`

Unity에서 전환 클립을 반복 재생하지 말 것. Idle 복귀와 다른 반응 클립에는 짧은 크로스페이드를 사용한다. 기존 unity/DogClipTester.cs는 Idle/Walk만 검사하므로 위 상태 연결은 앱 쪽에서 추가해야 한다. 이번 작업은 Unity 코드/씬을 수정하지 않았다.

## 재발 검사

```
python tools/check_regression.py
./run_all.ps1 -OutputRoot output_repeat
python tools/check_regression.py --repeat output_repeat
```

- 기본 검사는 3개 모델의 기존 감사 결과와 접지·늘어남을 비교하고, 유지 자세 떨림·반복 경계·GLB 채널 계약을 확인한다.
- 반복 검사는 입력 해시, 뼈 길이, 클립별 접지·늘어남 수치의 허용 오차 내 재현을 확인한다. 바이너리 파일이 완전히 같다는 검사는 아니다.
- `tools/check_roundtrip.py`를 Blender -b -P로 실행하면 17개 클립당 3프레임을 GLB 재수입 결과와 비교한다. 메시 경계 비교이며 모든 정점/서브프레임의 완전 동등성 증명은 아니다.
- `audit/regression-result.json`, `audit/roundtrip-result.json`에 결과를 남긴다.
- 원본 소스 백업: backups/before-contact-fix/. 기존 모델 결과: output/.

## 남은 한계

이 구현은 지원 모델의 재생성을 개선하고 실패를 드러내는 장치다. 임의의 GLB를 항상 완벽하게 리깅하는 해법은 아니다. 팔·다리 자기 관통, 실제 발 미끄러짐, 지지 다각형에 대한 무게중심, 서브프레임 접지, 새 체형, Unity 재생은 추가 검토 대상이다. 바인드 대비 늘어남 경고는 여전히 사람이 확인해야 한다. 사용자에게 모든 모션의 품질 문제가 해결됐다고 보고하지 말 것.

특히 m3_cream의 엎드린 유지 자세는 앞다리 말림을 완화했지만 몸통이 높아 웅크린 모습에 가깝다. 최저점 접지 통과만으로 몸통이 바닥에 닿는 자연스러운 엎드리기를 보장할 수 없다. 체형별 몸통 접촉 조건을 추가하고 손 포즈의 시각적 의도를 다시 맞추는 작업이 남아 있다.

## 이번 재생성에서 확인한 개선

모델 높이=1 기준 비율이며 실제 cm가 아니다.

| 앉은 유지 자세 최대 침범 | 기존 | 수정 |
|---|---:|---:|
| m1_golden | 7.56% | 약 0.30% |
| m2_white | 4.39% | 약 0.50% |
| m3_cream | 3.84% | 약 1.00% |

기존 m1/m3의 최저 침범은 꼬리 정점이었다. 기존 문서의 '엉덩이 침범'이라는 원인 설명은 부정확했다. 꼬리와 뒷다리 영향을 분리해 측정해야 한다.

접지는 개선됐지만 늘어남은 모든 모델에서 일괄 감소하지 않았다. m1 SitIdle의 바인드 대비 p99는 약 2.74→2.23으로 감소했지만 m2/m3는 일부 증가했다. 현재 회귀 검사는 늘어남 15%+0.02 이내의 변화만 허용하며, 이 통과를 '늘어남 문제 해결'이라고 해석하면 안 된다. 별도 품질 게이트에서는 남은 늘어남 경고 때문에 세 모델 모두 needs_review다.

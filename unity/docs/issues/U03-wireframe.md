- 날짜: 2026-10-29
- 상태: 시안 생성·파일 검증 완료, 사용자 확인 대기. U03 구현 완료가 아님.
- 요청: 프로젝트 문서 분석을 바탕으로 추억 앨범을 제외한 SVG를 `unity/docs/wireframe/`에 생성.
- 산출물: [전체 보기](../wireframe/00-overview.svg), [화면 목록·가정·이동 경로](../wireframe/README.md).
- 범위: 로그인·인증·자료 등록·동의·이미지 생성·4면 확인·3D 생성·관절 보정·움직임 확인·외형 확정·습관·함께하기·사진 모드·설정·실제 소리·실패 복구·즉시 나가기 도착 화면. 17개 화면과 전체 SVG 1개.
- 제외: 앨범·A5·장난감의 앨범 연결. 사용자 요청에 따른 시안 범위이며 PRD 변경이 아님.
- 가정: 모바일 세로 390 × 844. 사진 모드에서 참고 사진 열람, 조용한 즉시 나가기 도착 화면은 제안. SVG 속 사진·모델·4면은 자리 표시자이며 실제 생성 결과가 아님.
- 검증: SVG 18개 XML 파싱 성공, 외부 리소스 참조 없음. 전체 시트·관절 보정·외형 확인·함께하기를 PNG로 렌더링해 한글과 요소 배치를 확인.
- 미실행: 실제 화면 이동·터치·스크린리더·Android 기기 가독성·Unity 컴파일·APK. 이번 작업은 설계 문서이며 앱 파일은 수정하지 않음.
- 다음: 사용자 시안 검토 후 화면 방향·문구·배치·예외 상태를 확정. 별도 구현 요청 전 Unity UI 배치 금지.

## v0.2 문구 수정

사용자 요청으로 SVG 18개의 사용자 문구를 제작 중심에서 찾아보기·확인·만나기로 수정했다. 대표 문구는 ‘사진으로 강아지를 찾아볼게요’, ‘당신의 강아지가 맞나요?’, ‘네, 이 모습으로 만날게요’다. 모델·관절·태그 등의 표현을 일상어로 바꾸고 AI 표현 안내·외부 전송 동의는 유지했다. XML 파싱과 개별 화면 한글 가로폭 검사 후 동의·모습 확인·소리 관리 화면을 렌더링해 검토했다. 화면 구조와 앱 파일은 변경하지 않았다.

## v0.3 걸음 확인 후 선택 수정

사용자 요청으로 기본 흐름을 자동 리깅 후 걸음 확인으로 변경했다. 걸음 확인 화면의 ‘움직임이 어색해요’를 선택할 때만 점 위치 수정 화면을 연다. 자연스러우면 외형 확인으로 진행하며, 수정 후에는 리깅 대기를 거쳐 걸음을 재확인한다. 수정 없이 돌아가기도 제공한다. 08/09 개별 SVG·전체 보기 순서·설명·화면 링크를 갱신했다. 실제 자동 리깅과 앱 화면 전환은 구현하지 않았다. 기존 상위 PRD의 필수 관절 보정과 달라진 점은 사용자 변경 사항으로 기록하며, 구현 전 API·자동 추정·리깅 단계 연결을 점검해야 한다.

## v0.4 외형 선택 수정·질문 연속 화면

사용자 요청으로 09를 모습·움직임 통합 확인으로 바꿨다. ‘외형이 어색해요’ 선택 시에만 10 외형 수정을 열며, 수정 후 09로 돌아온다. 명시적 확정은 09에서 수행하고, 수정 화면에서는 하지 않는다. 습관 설정은 한 화면 한 질문과 선택지 두 개로 나누었다. 11(반기는 모습) → 11b(쉬는 자세) → 11c(장난감) → 11d(평소 모습) → 12(함께하기) 순서이며 이전 질문 링크를 제공한다. 전체 시트는 20개 화면, SVG 총 21개로 갱신했다. SVG는 정적 예시이며 실제 선택 상태·이전 답변 유지·API 확정은 구현하지 않았다. XML·파일 링크·질문 수·텍스트 가로폭 검사와 주요 변경 화면 렌더 검토를 수행한다.

## v0.5 3D 메인·통합 메뉴

사용자 요청으로 등록 완료 후 앱을 열 때마다 12의 강아지 3D 공간을 기본 화면으로 표시하도록 설계했다. 이전에 보던 사진·메뉴 화면보다 3D 메인을 우선한다. 미등록·미확정·인증 만료는 별도로 분기하며 확정 전 진입 금지를 유지한다. 12는 전체 화면 3D 공간과 상호작용·메뉴 진입점으로 단순화했다. 비상호작용 기능은 14 통합 메뉴로 모았으며, 사진 화면도 같은 메뉴를 사용한다. AI 표현 안내는 메뉴의 강아지 정보에 표시한다. 즉시 나가기·음소거의 메뉴 이동은 사용자 지시로 반영한 PRD 배치 변경이다. 전체 시트는 3D 메인·통합 메뉴부터 보여 주도록 재정렬했다. 앱 진입 로직·실제 메뉴 기능은 구현하지 않았다.

## 시작하기 문구 보완

‘초대받은 이메일’을 ‘이메일 주소’로, 초대 대상 안내를 ‘이메일로 받은 코드를 입력하면 시작할 수 있어요.’로 변경했다. 개별 시작 화면과 전체 시트에 함께 반영했다. 화면 문구 변경이며 서버의 초대·접근 정책 변경을 뜻하지 않는다.

# 곁에 UI 와이어프레임 v0.5

2026-10-29 작성. 사용자 요청에 따라 추억 앨범을 이번 시안에서 제외했다. Unity 씬·프리팹·코드는 변경하지 않았다.

[전체 보기](00-overview.svg) · 각 화면은 390 × 844 SVG. 한국어 텍스트와 벡터 도형으로 구성했으며 외부 이미지·스크립트·폰트 다운로드가 없다. Noto Sans KR / 맑은 고딕 / sans-serif 순으로 표시한다.

## 범위와 가정

- v0.5 기본 진입: 강아지 등록과 모습 확정이 완료되어 있고 인증이 유효하면 앱을 열 때마다 12의 강아지 3D 화면을 먼저 표시한다. 별도 홈·대시보드·메뉴 화면을 먼저 띄우지 않으며, 이전에 메뉴나 사진 모드를 보고 종료했어도 다음 앱 시작은 3D 메인이다. 인증이 만료됐다면 인증 후 12로 돌아온다.
- 등록 전·미확정 상태는 기존 작업 이어하기 또는 사진 이용 경로로 분기한다. 확정 전 방 진입 금지는 유지한다. 3D 파일을 읽는 동안은 같은 메인 공간에서 준비 상태를 표시하며 로드 실패 시 사진 보기·재시도를 안내한다. SVG는 이 진입 규칙을 설명하는 시안이며 실제 앱 라우팅을 구현한 것이 아니다.
- 12는 카드형 대시보드 대신 전체 화면 3D 공간이다. 사용자 조작은 A1 직접 쓰다듬기·A2 불러보기·A3 장난감·A4 곁에 앉기와 메뉴 진입점만 노출한다. 이름·AI 안내·사진 모드·음소거·설정·즉시 나가기는 메뉴로 모은다. 메뉴 아이콘은 비상호작용 기능을 여는 유일한 진입점이다.
- 14는 별도의 설정 목록이 아닌 통합 메뉴다. 음소거·동작 줄이기·사진 보기·즉시 나가기·이름과 사진·습관 질문·소리 관리·모습과 움직임 확인·동의와 계정 안내를 한곳에서 제공한다. 닫기는 원래 화면으로 돌아온다. 정적 SVG의 닫기 링크는 등록 완료 상태를 대표해 12로 연결했다. 미등록 사진 이용 중에는 13으로 돌아와야 한다.
- 기존 PRD의 즉시 나가기·음소거는 유지하되 사용자 요청에 따라 메뉴 안으로 이동했다. 메뉴의 즉시 나가기를 선택하면 동작·소리 재생을 멈추고 17로 이동한다. 이름·사진 수정은 실제 구현 시 등록을 새로 시작하지 않고 편집 후 메뉴로 복귀해야 한다. 확정 후 모습 재수정은 새 결과 확인 전까지 기존 확정 모습을 보존해야 한다.

- v0.2 문구 방향: 사용자 요청에 따라 제작 도구 중심의 표현을 ‘사진으로 강아지를 찾아보기 → 우리 아이인지 확인하기 → 함께 만나기’로 바꿨다. ‘사진으로 강아지를 찾아볼게요’, ‘당신의 강아지가 맞나요?’, ‘네, 이 모습으로 만날게요’를 사용한다.
- 사용자 화면에서는 모델·관절·리깅·태그·외형 확정 등의 기술 용어 대신 모습·점 위치·어떤 소리인지·만나기로 표현한다. 아래 설계 설명과 파일명은 기술적 의미를 구분하기 위해 유지한다.
- AI가 사진을 바탕으로 표현한 모습이라는 안내와 Gemini(Google)·Meshy 사진 전달 동의는 유지한다. 실제 강아지의 귀환·의식 복원을 뜻하는 문구는 사용하지 않는다.

- 앨범 화면·하단 앨범 탭·A5 추억 꺼내기·장난감의 앨범 연결을 제외했다. 상위 PRD에서 기능을 삭제한 것은 아니다.
- 세로형 모바일은 검토를 위한 가정이며 최종 화면 방향·색·여백·문구는 미확정이다.
- 사진·모델·4면 이미지는 자리 표시자다. 방향별 실제 3D 모델이나 생성 결과의 품질을 표현한 것이 아니다.
- 생성 중에는 사진 모드 또는 나중에 이어하기를 제공한다. 재접속은 기존 작업을 조회한다.
- 동의 전 외부 전송 금지. 동의하지 않으면 사진 모드로 이동한다. 동의 버튼은 미선택 비활성 상태를 표현했다.
- v0.3: 먼저 자동으로 움직임을 준비하고 걸음을 보여 준다. ‘움직임이 어색해요’를 선택했을 때만 점 위치 수정 화면으로 이동한다. 처음부터 모든 사용자에게 뼈대·관절 수정을 요구하지 않는다. 기존 상위 문서의 필수 관절 보정 흐름에 대한 사용자 변경 요청이며, 현재 SVG 시안에 반영한 상태다.
- v0.4: 4면 확인 → 자동 움직임 준비 → 09 모습·움직임 확인을 기본으로 한다. ‘움직임이 어색해요’는 08, ‘외형이 어색해요’는 10으로 이동한다. 수정은 필요한 경우에만 진행한다. 미확정 모델은 제작 미리보기에서만 표시한다.
- 08은 점 위치 수정 후 움직임을 다시 준비하고 09로 돌아온다. 10은 외형 수정 후 09로 돌아와 움직임까지 재확인한다. 수정 없이 돌아가기도 제공한다. 대기 화면은 05/07의 틀을 재사용한다.
- 명시적 확정은 09의 ‘네, 이 모습으로 만날게요’에서 수행한다. 확정 후 11부터 질문 네 개를 순서대로 답하고 12로 이동한다. 10에서 바로 확정하거나 방으로 이동하지 않는다.
- 11 / 11b / 11c / 11d는 한 화면에 질문 하나와 선택지 두 개를 표시한다. 질문은 반기는 모습 → 쉬는 자세 → 좋아하던 장난감 → 평소 모습 순서다. 선택 후 ‘다음 질문’으로 진행하며 이전 질문으로 돌아가도 실제 앱에서는 답을 유지해야 한다. 마지막 버튼은 ‘보리와 함께하기’다.
- SVG의 버튼에 상대 파일 링크를 연결했다. 뷰어에서 화면 연결을 살펴볼 수 있지만 실제 리깅·확정·선택 저장 처리를 실행하지 않는다. 질문의 첫 선택지가 선택된 상태는 시안 예시이며 자동 선택 정책을 뜻하지 않는다. 전체 보기 번호는 읽는 순서이며 기존 파일명과 다를 수 있다.
- 12는 A1 직접 쓰다듬기, A2 불러보기, A3 장난감, A4 곁에 앉기를 제공한다. 불러보기는 음성 인식이 아니다.
- 13의 사진 넘기기는 대표·참고 사진 열람 제안이며 앨범 CRUD가 아니다. 사진 화면에는 메뉴 버튼을 두고, 우리 아이 찾아보기·진행 이어하기는 미제작 / 진행 중 상태에 맞춰 메뉴 안에서 표시한다. 등록 완료 메뉴에서는 해당 제작 CTA 대신 모습·움직임 다시 보기를 표시한다.
- 15의 태그 변경·행동 연결·목록은 별도 상태로 확장할 자리다. 녹음·영상 업로드는 선택이며 음원 조각 편집과 합성은 제공하지 않는다.
- 16은 작업 실패 예시다. 통신 실패·재시도 한도·차단 사유는 실제 서버 상태에 맞춰 다른 문구와 버튼으로 표시한다. 정확한 재생성 횟수 문서 불일치로 횟수 숫자는 넣지 않았다.
- 17은 즉시 나가기의 도착점 제안이다. 모든 동작·재생을 중단하고 조용한 화면으로 이동하며, 돌아가기는 확정 캐릭터 유무에 따라 분기한다.
- 설정의 자료 삭제는 문의 절차로 연결한다. 앱 내 즉시 전체 삭제 기능을 추가하지 않는다.

## 주요 이동

**등록 완료 후 기본 진입:** 앱 시작 → 인증·등록 상태 확인 → 12 강아지 3D 메인. 이전 메뉴·사진 화면을 시작 화면으로 복원하지 않는다.

**첫 등록·제작 경로:**

01 → 02 → 03 → 04 → 05 → 06 → 07 → 자동 움직임 준비 → 09에서 확정 → 11 → 11b → 11c → 11d → 12

- 09 ‘움직임이 어색해요’ → 08 점 위치 수정 → 움직임 다시 준비 → 09 걸음 재확인.
- 09 ‘외형이 어색해요’ → 10 모습 다듬기 → 09 모습·움직임 재확인.
- 08 / 10 ‘수정하지 않고 돌아가기’ → 09. 최종 확정은 수정 화면이 아닌 09에서만 수행한다.

- 동의 거부·제작 중·실패: 13 사진 모드.
- 12 / 13 → 14 통합 메뉴 → 사진 보기·습관·소리·정보·계정 관리. 메뉴 닫기는 원래 화면으로 복귀한다.
- 제작 실패: 16 → 사진 모드 또는 작업 상태 확인.
- 즉시 나가기: 12 / 13 → 14 메뉴 → 즉시 나가기 → 17.

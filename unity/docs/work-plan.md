이 표는 Unity의 요청·진행·결과 표시를 중심으로 관리한다. Blender 리깅·클립 통합은 새 일괄 실행 계획 A~F에서 함께 수행하고, 다른 담당자의 worker 배포·실제 API 제공·공동 합의는 외부 의존성으로 구분한다. 다른 담당자의 작업까지 완료로 표시하지 않는다.

## 먼저 필요한 입력

- 테스트용 리깅 GLB, 공용 애니메이션, 표준 뼈대 규격·버전. 미제공 시 단순 프리미티브 동작을 GLB 검증 완료로 취급하지 않는다.
- API 기준 URL, 인증·오류 형식, 목 응답과 실제 서버의 준비 상태.
- 화면 기준 또는 사용자가 확인할 기본 UI 방향.
- APK 설치용 기기와 Android 빌드 모듈. 성능 기준 기종 확정은 마지막 측정 전에 진행한다.

## UI 검토 산출물

시작하기 문구는 ‘이메일 주소’와 ‘이메일로 받은 코드를 입력하면 시작할 수 있어요.’로 보완했다. 초대 여부를 이메일 입력 라벨로 요구하지 않으며 서버 접근 정책은 별도다.

2026-10-29 사용자 요청으로 [SVG 와이어프레임 v0.5](wireframe/README.md)을 작성했다. 추억 앨범·A5는 이번 시안에서 제외했다. 개별 화면 20개와 전체 보기 1개를 생성하고 XML 검사·렌더 검토를 수행했다. v0.2에서는 제작 용어를 ‘강아지 찾아보기·우리 아이인지 확인·만나기’ 문구로 수정했다. v0.3에서는 자동으로 준비한 걸음을 먼저 보여 주고 ‘움직임이 어색해요’를 선택할 때만 점 위치를 수정하도록 변경했다. v0.4에서는 외형도 선택 수정으로 바꾸고, 모습·움직임 확인에서 최종 확정하도록 합쳤다. 습관은 한 화면 한 질문으로 네 화면에 나눴다. v0.5에서는 등록 완료 후 매번 3D 메인으로 진입하고 상호작용 외 기능은 통합 메뉴로 이동하도록 변경했다. 기존 상위 PRD와 달라진 흐름은 사용자 변경 사항으로 기록했다. 세로형·사진 모드·즉시 나가기 도착점은 가안이며 사용자 확인 전이다.

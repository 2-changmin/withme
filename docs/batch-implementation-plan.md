# 리깅·동작·Unity 일괄 작업 실행 계획

- 작성일: 2026-10-30. 기준 커밋: `42838484` 및 사용자 제공 `dog-rig.zip`, `dog_sounds.zip`.
- 목적: 황세인 담당 잔여 이슈를 작은 작업으로 분해해 순차 실행하고, 외부 의존성이 있는 부분은 목 검증과 실제 연결을 구분한다.
- 현재 상태: 내부 PC/목 구현·인수 기록을 마쳤고 품질 보완/시각 승인·외부 API/기기 확인이 남았다. 예약은 중지했다. [인수 결과](batch-acceptance.md)와 [진행 기록](batch-progress.md)을 따른다. 첨부 정적 조사나 목 통과를 실제 서비스/품질 승인으로 계산하지 않는다.
- 범위: #1~5, #7 PC 부분, #11~13. #17은 Git 규격 적용·합의 자료 준비까지, #8·#15·#52는 남은 실인증·기기 인수 조건을 관리한다.
- 실행 원칙: 한 작업을 구현하고 해당 검증을 통과한 뒤 다음 작업으로 이동한다. 단계마다 진행 허가를 다시 묻지 않는다. 외부 의존성·품질 판단으로 멈춘 항목은 기록하고 독립적인 화면·목 작업을 계속한다.

## 1. 고정 조건

1. **관절 JSON의 정식 기준은 Git의 [04-api-data.md](04-api-data.md#관절-데이터-형식)와 현재 서버 스키마다.** 첨부 임시 JSON을 앱·서버 공개 계약으로 채택하지 않는다.
2. 이름 10개: `nose`, `neck`, `tail_base`, `tail_tip`, `front_paw_l`, `shoulder_l`, `hind_paw_l`, `hip_l`, `ear_tip_l`, `ear_base_l`.
3. 외부 형식은 `skeletonVersion: 1`, `space: "normalized"`, `joints`다. 정면 +Z·위 +Y·바닥 y=0·키 1, 오른쪽은 x 대칭이다. Unity 임포터의 좌우 변환까지 포함해 실제 왕복 검증한다.
4. 자동 준비된 움직임을 먼저 보여 준다. ‘움직임이 어색해요’에서만 관절 수정, ‘외형이 어색해요’에서만 외형 수정으로 들어간다. 최종 모습 확정은 모습·움직임 확인 화면에서 수행한다.
5. 습관은 한 화면 한 질문으로 4개를 순서대로 묻는다. 등록 완료 후 앱 시작 화면은 강아지 3D 메인이다. 상호작용 외 기능은 통합 메뉴로 모은다. 음소거·즉시 나가기도 메뉴 안에서 실제로 조작 가능해야 한다.
6. 추억 앨범·A5·보호자 녹음 분할은 이번 실행 대상에서 제외한다. 기존 기본 효과음을 연결한다. #76 전체 물건 생성·가챠는 별도 범위이며 #13의 기본 장난감 쫓기를 막지 않는다.
7. Unity 6000.0.76f1·기존 uGUI·Input System·glTFast를 유지한다. PC 기능 검증을 먼저 하고 APK·실기기는 사용자 지시대로 보류한다.
8. 원본 ZIP·GLB·기존 #7 검증 결과·사용자 미커밋 파일을 덮어쓰지 않는다. 실제 Gemini·Meshy 호출·과금·운영 배포를 이 계획 작성이나 목 검증에 포함하지 않는다.

## 3. 실행 순서

기본 순서는 **A 자료·환경 → B 계약 → C 메시·뼈대 → D 리깅 품질 → E 공용 동작·PC 재생 → F 작업자 연결 → G 관절 보정 → H 외형·습관 → I 방·소리 → J 통합 인수**다.

각 표의 한 행이 별도 구현·검증 단위다. `산출물`은 예정 경로 또는 결과이며 이미 생성됐다는 뜻이 아니다. 상태는 다음 표기만 사용한다.

- `미착수` / `진행 중` / `자동 검증 통과` / `사용자 확인 대기` / `외부 대기` / `완료`.
- 한 모델·한 클립만 통과한 경우 범위를 함께 적는다. 품질 경고가 남으면 `완료`로 옮기지 않는다.

## 4. 실행을 중단하지 않는 대체 순서

| 막힌 항목 | 진행할 수 있는 독립 작업 | 계속 금지되는 완료 주장 |
|---|---|---|
| Blender 설치/버전 | 제공 보정 GLB로 E01, 계약 B01~B04, G01/G03, H01/H04 화면 | 재리깅·버전 호환·신규 .blend 생성 성공 |

| 실제 worker 배포 | F03 로컬 목·G06 재시도/복구·J01/J02 | 실제 Blender 서버 연동·운영 리깅 성공 |

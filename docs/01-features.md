## 상호작용 A1~A5

| ID | 행동 | 캐릭터 반응 |
|---|---|---|
| A1 | 쓰다듬기 | 머리·배·턱 부위별 반응 |
| A2 | 불러보기 | 고개를 들고 다가와 반기기 |
| A3 | 장난감 던지기 | 공 쫓기 후 돌아오기 (3~6초) |
| A4 | 곁에 앉기 | 옆에 앉거나 엎드림 |
| A5 | 추억 꺼내기 | 앨범 미디어 재생 후 이전 상태로 복귀 |

LLM·영상 API 호출 없이 준비된 애니메이션만 쓴다.

## 하지 않는 것

내보내기(ZIP), 운영자 관리 화면, AR, 실사 3D, 자체 모델 학습, 소리 합성·복제, 자유 대화, 반려견 명의 편지, 감정 추론, 돌봄 의무, 공개 피드, 결제, 고양이.
필요하면 다음 버전 범위로 논의하고, P0에 조용히 추가하지 않는다.

## 사용자 흐름

보호자가 직접 개입하는 지점은 **세 곳**(4면 확인, 관절 보정, 외형 확정)이다.

```
 1. 로그인          이메일 인증 코드 → AI 표현·외부 전송 안내 (정적 화면)
 2. 등록            이름, 사진 1~4장(무늬가 잘 보이는 사진 권장), 선택으로 소리·영상
 3. 4면 이미지 생성   (약 30초) 서 있는 옆모습 기준 1장 → 앞·뒤·반대쪽 옆모습 3장
 4. 4면 확인 ✋       "우리 아이 맞아요" / "다시 만들기" (최대 3회)
 5. 3D 생성          (2~5분) 진행률 표시, 앱을 닫아도 계속 진행, 기다리는 동안 앨범 이용 가능
 6. 관절 보정 ✋       3D 모델 위에 자동 추정 관절 10개 → 틀린 점만 드래그 (좌우는 대칭 자동)
 7. 자동 리깅         (10~30초) 완료되면 걷기 미리보기
 8. 외형 수정·확정 ✋   원본 사진 나란히, 귀 크기·각도, 꼬리, 다리 길이, 털 색 보정 → 확정 버튼
 9. 습관 설정 → 나의 방   A1~A5 + 실제 소리
```

**실패할 때**
- 4면 이미지 3회 모두 거절 → 사진 바꿔서 다시 시작, 또는 사진 모드로 이용
- 3D 생성 실패 → 1회 자동 재시도, 그래도 실패하면 안내 후 사진 모드
- 리깅 결과가 어색함 → 관절 다시 지정 (최대 2회)

**규칙**
- 확정 전에는 방에 들어갈 수 없다.
- 생성 중에 앱을 닫았다가 다시 열면 마지막 단계부터 이어서 진행한다.

## 실제 실행한 검사

- Python: 관절 9개+작업자 8개=17개, 로컬 HTTP 3개 묶음 통과.
- Unity 핵심: 로그인 8개, 등록/업로드 8개, 생성 9개, 리깅 9개 묶음 통과.
- Unity 화면: 로그인→등록/업로드→4면 확인/재시도→자동 리깅/걷기 7개, 관절 편집 9개, 외형 6개, 확정/습관 5개, 방 13개, 리깅 실패/사진 이용 3개 묶음 통과.
- 리깅 완료 상태 및 **Blender 진행 중**에 Play를 종료·재시작하고 같은 모델/리깅 작업 ID로 재개했다. 새 제출 없이 기존 작업 조회로 복구했다.
- 잘못된 숫자/JSON·다른 모델 응답·잘못된 GLB·저장 실패·응답 유실·사용자 분리·중복 입력을 검사했다. 실제 OTP/서명 URL 만료 서버 자체를 재현한 것은 아니다.
- 공용 동작 102경우: 관절 최대 오차 `2.46207577e-7`, 비골반 위치 드리프트 0, 반복 경계 각도 0. 실제 Walk/Trot 스킨 변형 확인.
- 추가 체형 검사: 3모델의 비 root 관절 96개를 각각 30도 굽혀 유한 스킨·반대편 낮은 발의 과도한 변위 여부를 검사했다. 해당 검사 경고 0. 외형 길이/귀/머리/꼬리/색 변경 후 3×17=51경우도 유한 좌표·원본 재질 복원을 통과했다. 기존 전체 자세 품질 경고의 해소를 뜻하지 않는다.
- 동일 입력을 새 출력으로 재생성: 3모델 모두 578개 채널 최대 차이 0, 뼈 길이·bind matrix·스킨 웨이트·메시/UV/노멀/인덱스 일치. 품질 미승인 상태도 보존.
- 방: 단일 입력 소유권, 실제 버튼/강아지 표면 포인터 입력, 장난감 약 3.00초 복귀, 20음원·pitch ±5%, 중단·음소거·사진·즉시 나가기·로그아웃 정리 검사.

## 남은 품질 경고

메시 삼각형: m1=19,900 / m2=19,899 / m3=19,899. 경고는 각각 13 / 5 / 18개이며 모두 `needs_review`, `accepted:false`다. 자동 경고가 없는 클립도 시각 승인된 것은 아니다.

표의 S=늘어남, G=바닥 침범, F=발 접지다. 원본 수치·기준은 GLB 옆 `.quality.json`과 `blender/dogrig/validate.py`를 따른다.

| 클립 | m1 golden | m2 white | m3 cream |
|---|---|---|---|
| Idle / Walk / Trot / HeadTilt | — | — | — |
| Greet | S | S | S |
| PetHead | S | — | — |
| PetChin / PetBelly | S | — | S |
| SitDown / StandUp | S | S | S+G+F×2 |
| SitIdle | S | S | S |
| LieDown / LieIdle / GetUp | S | — | S |
| Sleep | S | S | S |
| FallAsleep / WakeUp | S | — | S |

동일 m1 입력에서 smoothing을 4→8회로 늘린 실험은 경고 13→13이었다. Walk의 p99 변화는 0.428→0.417이지만 Greet 0.982→1.022, SitIdle 1.757→1.838 등 악화가 있어 채택하지 않았다. 기준을 느슨하게 하거나 경고를 삭제하지 않았고 정식 파이프라인/fixture는 유지했다. 실험은 `Temp/batch/quality-experiments/m1_smoothing8/`에 별도 보존한다.

정면 17개+주요 동작 옆모습 6개, 총 23장과 manifest를 `Temp/batch/review/`에 저장했다. 옆모습의 몸통/다리·접지, 흰 모델의 털 주변 돌출, 앉기/엎드리기 자세를 우선 확인해야 한다. 이 자료는 클립 중간 시점 캡처이며 전체 시간축의 자연스러움을 대신하지 않는다.

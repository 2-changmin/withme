## 11/01 관문

**통과 기준**: 사진 → 4면 이미지 → Meshy GLB → Blender 리깅을 거친 강아지 1마리가 **기준 폰에서 대기·걷기 애니메이션을 재생**하고, 다리를 움직일 때 몸통이 심하게 늘어나지 않는다.

**미통과 시 선택지** (11/01 전원 결정)
1. 리깅 품질 문제 → 관절을 보호자가 직접 찍는 방식으로 축소
2. 생성 품질 문제 → 4면 대신 옆모습 1장만 Meshy에 입력
3. 둘 다 안 됨 → 리깅 없이 정적 3D 모델 + 사진 모드로 데모

## 바뀐 범위 (10/30)

- 소리: 보호자 녹음 분할(#33) 대신 기본 효과음을 앱에 넣어 쓴다 (PR #73).
- 동의: 서버의 동의 저장·확인을 없앤다. 외부 전송 안내는 앱 화면에 정적 문구로만 둔다.
- 포인트: 장난감 가챠의 포인트 차감은 화면 연출만 하고 실제로 차감하지 않는다 (#76).
- 화면 축소: 앨범·소리 태그·사진 모드·동작 줄이기 화면(#14)과 앨범 API(#31), A5 추억 꺼내기를 뺀다. 소리 끄기·즉시 나가기는 나의 방(#13)에 버튼으로 둔다.

## 일정이 밀릴 때 축소 순서

1. 관절 자동 추정 → 보호자가 10개 직접 찍기 (황세인)
2. 4면 생성 → 옆모습 1장만 (윤승희·이창민)
3. 외형 수정 항목 → 귀·꼬리 크기만 (황세인)
4. 애니메이션 → 대기·반기기·쓰다듬기·공 쫓기만 (황세인)

**절대 줄이지 않는 것**: 원본 열람, 음소거, 즉시 나가기, 명시적 확정, 사용자 간 접근 차단, 삭제 요청 처리 절차.

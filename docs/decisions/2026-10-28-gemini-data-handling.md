# Gemini API 데이터 처리 조건과 사용 규칙

- 상태: 제안 (장세찬·박재현 승인 후 채택)
- 날짜: 2026-10-28
- 작성: 윤승희 (#41)
- 관련: [03-3d-pipeline.md](../03-3d-pipeline.md) 1장, [08-quality-ethics.md](../08-quality-ethics.md) 윤리와 개인정보

## 배경

4면 이미지 생성(F04)은 보호자가 올린 반려견 사진을 Google Gemini API로 보낸다.
08 문서는 "입력 보존 기간과 학습 이용 여부를 확인하기 전에는 실제 보호자 사진을 보내지 않는다"고 정했다.
이 문서는 Google 공식 문서로 확인한 조건과, 실제 사진을 보내기 위해 지켜야 할 규칙을 정한다.

## 확인한 사실 (2026-10-28 기준)

| 항목 | 내용 | 출처 |
|---|---|---|
| 유료·무료 구분 | 결제(Cloud Billing)가 켜진 프로젝트의 호출은 **유료 서비스**, 아니면 **무료 서비스** 약관을 따른다 | 추가 약관 |
| 학습 이용 — 무료 | 입력과 결과를 **제품 개선·개발에 사용**하고, **사람 검토자가 읽을 수 있다.** "민감·개인 정보를 보내지 말라"고 명시 | 추가 약관 Unpaid Services |
| 학습 이용 — 유료 | 프롬프트와 결과를 **제품 개선에 쓰지 않는다** | 추가 약관 Paid Services |
| 남용 감시 보관 | 유료·무료 모두 입력·맥락·결과를 **55일** 보관. 정책 위반 탐지 전용이고 일반 모델 학습에 쓰지 않음. 위반이 의심될 때만 승인된 Google 직원이 검토 | 남용 감시 정책 |
| 보관 면제(ZDR) | Gemini API에는 보관 면제 옵션이 **안내되어 있지 않다** | 남용 감시 정책 (언급 없음) |
| 프로젝트 로그 | 결제가 켜진 프로젝트에 요청·응답 로그가 저장된다. **2026-10-26 이후 만든 프로젝트는 Generate Content 로그가 기본으로 켜짐.** 기본 보관 55일, 7·14·28·55일로 줄이거나 끌 수 있다. 우리 프로젝트에만 보이며, **데이터셋으로 공유하거나 피드백을 보내면 학습에 쓰일 수 있다** | 로그 정책 |
| 처리 지역 | 한국은 이용 가능 지역. 다만 로그 데이터는 "Google이나 대리인의 시설이 있는 **어느 나라에든** 일시 저장·캐시될 수 있다". 지역 고정 옵션 없음 | 이용 가능 지역, 추가 약관 |
| 나이 | API 사용자는 만 18세 이상, 18세 미만 대상 앱에 쓸 수 없다 | 추가 약관 |

## 결정

1. **결제가 켜진 프로젝트의 API 키만 쓴다.** 무료 등급 키로는 실제 보호자 사진을 보내지 않는다. 스파이크(팀원 반려견·공개 사진)도 같은 유료 키로 한다.
2. **AI Studio 로그는 끄거나 보관 7일로 줄인다.** 로그를 데이터셋으로 공유하거나 평가·피드백을 보내지 않는다. Contributor Tier(할인 대신 데이터 제공)에 가입하지 않는다.
3. **반려견 영역만 잘라서 보낸다** (#44). 사람·배경·위치 메타데이터는 보내지 않는다.
4. **동의 화면에 아래 내용을 적는다** (장세찬 F02). 동의하지 않으면 사진 모드와 앨범만 이용한다.
5. 파일럿 대상은 성인 보호자로 한정한다 (이미 PRD 조건).
6. 남용 감시 55일 보관은 피할 수 없다. 이 기간을 동의 문구와 삭제 요청 안내에 그대로 적는다.

### 동의 문구 초안 (장세찬 검수)

> 캐릭터를 만들기 위해 반려견이 보이는 부분만 잘라 **Google(Gemini)**에 보내요.
> - 목적: 서 있는 모습의 4면 이미지 만들기
> - Google은 이 사진을 AI 학습에 쓰지 않아요. 다만 부정 사용 감시를 위해 **최대 55일** 보관한 뒤 지워요.
> - 처리 위치: Google 시설이 있는 국외 지역에서 처리될 수 있어요.
>
> 동의하지 않아도 사진 모드와 추억 앨범은 똑같이 이용할 수 있어요.

## 운영 체크리스트 (실제 보호자 사진 전송 전)

- [ ] AI Studio에서 사용하는 키의 프로젝트에 결제가 켜져 있다 (윤승희)
- [ ] AI Studio **Logs and Datasets**에서 로그를 끄거나 보관 7일로 설정했다 (윤승희)
- [ ] 서버 `.env`의 `GEMINI_API_KEY`가 위 프로젝트 키다 (박재현)
- [ ] 반려견 영역 자르기·메타데이터 제거가 동작한다 (#44, 윤승희)
- [ ] 동의 화면에 위 문구가 들어갔다 (장세찬)

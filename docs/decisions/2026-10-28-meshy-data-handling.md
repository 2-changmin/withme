# Meshy API 데이터 처리 조건과 사용 규칙

- 상태: 제안 (장세찬·박재현 승인 후 채택)

- 작성: 이창민 (#48)
- 관련: [03-3d-pipeline.md](../03-3d-pipeline.md) 2장, [08-quality-ethics.md](../08-quality-ethics.md) 윤리와 개인정보, [Gemini 결정 기록](2026-10-28-gemini-data-handling.md)

## 배경

3D 생성(F05)은 4면 이미지를 Meshy API로 보낸다.
08 문서는 "입력 보존 기간과 학습 이용 여부를 확인하기 전에는 실제 보호자 사진을 보내지 않는다"고 정했다.
이 문서는 Meshy 공식 문서로 확인한 조건과, 실제 사진에서 나온 이미지를 보내기 위해 지켜야 할 규칙을 정한다.

**Meshy가 받는 것은 원본 사진이 아니다.** Gemini가 만든 4면 이미지(흰 배경, 반려견만, 1024px PNG)만 보낸다. 사람·배경·위치 메타데이터는 이 단계에서 이미 빠져 있다.

## 확인한 사실 (2026-10-28 기준)

| 항목 | 내용 | 출처 |
|---|---|---|
| 학습 이용 | Enterprise가 아닌 고객의 **입력과 결과를 서비스 학습·개선에 쓸 수 있다.** support@meshy.ai로 요청하면 **제외(opt-out)** 된다. 우리는 Pro 플랜이라 기본적으로 학습 대상이다 | 이용약관 §2.9 |
| 품질 평가 이용 | 입력·결과 일부를 평가·테스트에 쓸 수 있다. 제외 방법은 안내되어 있지 않다 | 개인정보처리방침 §3.5 |
| 결과 보관 (API) | Enterprise가 아닌 고객의 API 결과(모델)는 **생성 후 최대 3일** 보관 뒤 삭제된다 | 이용약관 §2.5, API Asset Retention 문서 |
| 입력 보관 | 입력 이미지의 보관 기간은 **명시되어 있지 않다.** "목적에 필요한 기간 동안" 보관한다고만 적혀 있다 | 개인정보처리방침 §8 |
| 즉시 삭제 | `DELETE /openapi/v1/{image-to-3d 또는 multi-image-to-3d}/:id`는 "작업과 모델, 데이터를 영구 삭제"한다. 진행 중(`IN_PROGRESS`)인 작업은 지울 수 없다(409) | API 문서 |
| 개인정보 입력 금지 | 입력에 **본인이나 제3자의 개인 식별 정보를 넣지 않는다**는 조건이 있다 | 이용약관 §2.2 |
| 결과 소유권 | 유료 플랜 고객이 결과물을 소유한다. 무료 플랜은 Meshy 소유이고 CC BY 4.0으로 공개된다 | 이용약관 §3.2 |
| 공개 여부 | 유료 플랜은 콘텐츠를 비공개로 둘 수 있다. 커뮤니티에 올린 결과만 CC0로 공개된다. API 결과는 커뮤니티에 올리지 않는다 | 이용약관 §3.2·§3.3 |
| 처리 지역 | **미국**에 저장되고, 세계 어디서든 처리될 수 있다 | 개인정보처리방침 §8·§10.3.1 |
| 삭제 요청 | support@meshy.ai로 요청하며, 처리에 **최대 30일**이 걸린다 | 개인정보처리방침 §9·§11.1·§13 |
| 나이 | 만 14세 미만 대상이 아니다 | 개인정보처리방침 §5 |

## 결정

1. **학습 제외(opt-out)는 요청하지 않는다.** 상용 서비스가 아닌 비공개 데모·파일럿(최대 10명)이라 필요성이 낮다고 판단했다. 대신 **동의 화면에 Meshy가 학습에 쓸 수 있다는 사실을 그대로 적는다.** 정식 출시 때는 학습 제외를 요청하거나 Enterprise를 검토한다.
2. **Meshy에는 Gemini가 만든 4면 이미지만 보낸다.** 원본 사진, 사람이 나온 이미지, 위치 메타데이터는 보내지 않는다 (§2.2 개인정보 입력 금지).
3. **GLB를 우리 버킷에 복사한 즉시 Meshy 작업을 삭제한다** (#49). 삭제가 실패해도 3일 뒤 자동 삭제되지만, 실패는 로그에 남기고 다시 시도한다.
4. **유료(Pro) 플랜 키만 쓴다.** 무료 플랜은 결과가 공개 라이선스로 풀린다. API 결과를 커뮤니티에 올리지 않는다.
5. **동의 화면에 아래 내용을 적는다** (장세찬 F02). Gemini 문구와 한 화면에 묶는다.
6. 파일럿 대상은 성인 보호자로 한정한다 (이미 PRD 조건).

### 동의 문구 초안 (장세찬 검수)

> 4면 이미지로 3D 캐릭터를 만들기 위해 **Meshy**(미국)에 이미지를 보내요.
> - 보내는 것: AI가 만든 4면 이미지만 보내요. 원본 사진은 보내지 않아요.
> - 결과물을 저장하면 Meshy에서 바로 지우고, 늦어도 3일 안에 지워져요.
> - Meshy는 보낸 이미지와 결과물을 자기 AI 학습·서비스 개선에 쓸 수 있어요.
>
> 동의하지 않아도 사진 모드와 추억 앨범은 똑같이 이용할 수 있어요.

## 운영 체크리스트 (실제 보호자 사진에서 나온 이미지를 보내기 전)

- [ ] `meshy_generate`가 GLB 복사 후 Meshy 작업을 삭제한다 (#49, 이창민)
- [ ] 서버 `.env`의 `MESHY_API_KEY`가 Pro 플랜 키다 (박재현)
- [ ] 동의 화면에 위 문구가 들어갔다 (장세찬)

## 스파이크 중 팀원 반려견 이미지

관문용 말티즈(#46)는 팀원 반려견 사진에서 만든 4면 이미지다. 사진 주인인 팀원에게 Meshy 전송(미국 처리, 학습 이용 가능)을 알린 뒤 보낸다.

## 검토한 대안

| 대안 | 장점 | 보류 이유 |
|---|---|---|
| 학습 제외 요청 (support@meshy.ai) | 메일 한 통, 비용 없음 | 비공개 데모라 필요성이 낮다. 입력 보관 기간도 이때 함께 물을 수 있다. 정식 출시 때 요청 |
| Meshy Enterprise | 학습 제외 기본, 보관 기간 1~30일 설정 | 별도 계약이 필요하고, 13일 일정과 데모 예산에 맞지 않는다. 정식 출시 때 다시 검토 |
| 원본 사진을 Meshy에 직접 전송 | Gemini 단계 생략 | 사람·배경이 섞여 §2.2 위반 위험이 있고, 앉은 자세라 리깅에 쓸 수 없다 |

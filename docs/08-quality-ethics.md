# 08. 품질, 윤리, 열린 질문

## 성공 지표

데모의 성공 기준은 **파일럿 보호자가 사진으로 만든 캐릭터를 확정하고 방에서 함께 지내는 것**이다. 수치는 팀 내부 판단용이며 앱에 "닮음 점수"로 보여 주지 않는다.

| 지표 | 목표 | 측정 |
|---|---|---|
| 사진 등록 → 캐릭터 확정까지 간 비율 | 파일럿의 60% 이상 | `character_versions.approved_at` (박재현) |
| 자동 리깅 1회 성공률 | 70% 이상 | `character_models.status` (장세찬) |
| 관절 보정에 걸린 시간 | 중앙값 2분 이내 | 화면 진입~제출 (황세인) |
| 사진 업로드 → 방 입장 전체 시간 | 중앙값 10분 이내 | 작업 타임스탬프 (박재현) |
| "우리 아이 같다" 응답 | 5점 척도 평균 3.5 이상 | 파일럿 설문 (장세찬) |
| 기준 폰 성능 | 30fps, 터치 반응 150ms, 방 진입 5초 | 측정 기록 (황세인) |

## 인수 테스트

API는 자동 테스트, 앱은 실제 기기 수동 시나리오. 실행·취합은 박재현.

| ID | 시나리오 | 통과 기준 | 담당 |
|---|---|---|---|
| T01 | 앉은 사진 1장·소리 없이 등록 | 캐릭터 또는 사진 모드로 끝까지 이용 | 윤승희 · 황세인 |
| T02 | 잘못된 형식·과대 파일 업로드 | 해당 파일 거부, 기존 자료 보존 | 박재현 |
| T03 | 3D 생성 요청 중복 탭·앱 재시작 | 중복 작업·중복 청구 없음, 이어서 진행 | 장세찬 · 이창민 |
| T04 | 4면 이미지가 실제와 다름 | 재생성·사진 모드 제공, 자동 확정 없음 | 윤승희 · 황세인 |
| T05 | 리깅 결과가 어색함 | 관절 재지정 가능, 확정 전 방 진입 불가 | 황세인 · 장세찬 |
| T06 | A1~A5 연속 실행·도중 나가기 | 상태 꼬임·소리 중첩·잔류 재생 없음 | 황세인 |
| T07 | 소리 미등록 | 무음 이용, 가짜 짖음 없음 | 박재현 · 황세인 |
| T08 | 기기 시계를 몇 주 뒤로 바꾸고 접속 | 상태 악화·출석 압박·알림 없음 | 황세인 |
| T09 | 계정 A가 B의 ID·파일 경로 요청 | 본문·메타데이터·다운로드 노출 없음 | 장세찬 · 박재현 |
| T10 | Meshy·Gemini 장애 | 실패 안내·사진 모드로 이동, 앨범 정상 | 이창민 · 윤승희 |
| T11 | 재로그인 | 확정 캐릭터·GLB·설정 유지 | 박재현 |

## 파일럿 평가

- 대상: 초대받은 보호자 최대 10명, 11/03~11/07
- 방법: 앱 사용 후 설문 + 20분 인터뷰 (장세찬 진행, 박재현 기록)
- 관찰: 4면 확인·관절 보정·외형 수정에서 막히거나 불편한 지점, 생성 대기 시간에 대한 반응

## 윤리와 개인정보

- 동의 화면에 **Gemini(Google)와 Meshy에 사진이 전달된다는 것**과 목적을 명시한다. 동의하지 않으면 사진 모드와 앨범만 이용한다.
- 두 업체의 입력 보존 기간과 학습 이용 여부를 확인하기 전에는 **실제 보호자 사진을 보내지 않는다**. 스파이크는 팀원 반려견 사진이나 공개 사진으로 한다.
- 외부로는 반려견 영역만 자른 사본을 보내고, 위치 메타데이터는 제거한다.
- Meshy 작업은 결과를 우리 버킷으로 복사한 뒤 `DELETE /openapi/v1/image-to-3d/:id`로 지운다.
- 화면에서 "사진을 바탕으로 AI가 만든 캐릭터예요"로 표시하고, "복원"·"되살렸어요" 같은 표현은 쓰지 않는다.
- 삭제 요청은 문의 창구로 받아 박재현이 수동으로 처리하고 기록한다.

## 데모 출시 체크리스트

- [ ] 사진으로 만든 3D 캐릭터 1건 이상이 등록부터 방 진입까지 연결된다 — 전원
- [ ] 원본 기록·편집한 소리·AI 캐릭터를 화면에서 구분할 수 있다 — 황세인
- [ ] A1~A5, 음소거, 사진 모드, 즉시 나가기가 동작한다 — 황세인
- [ ] 기준 폰에서 30fps·방 진입 5초를 지키거나 정적 대체로 이용할 수 있다 — 황세인
- [ ] 인수 테스트 결과가 기록되고 차단 결함이 없다 — 박재현
- [ ] 동의·외부 전송 안내, 문의 창구, 삭제 요청 절차가 준비되어 있다 — 장세찬 · 박재현
- [ ] Meshy·Gemini 데이터 처리 조건이 확인되어 있다 — 이창민 · 윤승희
- [ ] 비용 상한이 설정되어 있다 — 장세찬 · 이창민
